Inicio

Bienvenido al buscaminas. Versión sencilla, moderna y sin jQuery.

Elige una dificultad en el menú superior para comenzar a jugar.

Tecnologías

HTML, CSS y JavaScript moderno con módulos ES.

Objetivo

Descubrir todas las casillas seguras sin pulsar una mina.

Controles

Clic izquierdo para abrir. Clic derecho para poner o quitar bandera.

Partida

Selecciona una dificultad para empezar.

Puntuaciones

Se guardan en localStorage del navegador.

Cómo jugar

  1. Abre casillas con clic izquierdo.
  2. Marca sospechas con clic derecho.
  3. Los números indican cuántas minas hay alrededor.
  4. Ganas cuando descubres todas las casillas que no son minas.
